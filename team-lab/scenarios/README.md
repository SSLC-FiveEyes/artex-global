# 시나리오 설계 초안

> **2026-11-03 사용자 결정:** 프로젝트의 주 공격 시나리오는 아래 최신 계획의 스캔·MFA 로그인 우회 시도·사진 첨부를 통한 웹셸·최근 PHP 취약점이다. 기존 후보 JSON과 이전 설계는 보조 자료로 보존한다. 실제 준비 상태는 11/03 검증 기록을 확인하며, 이번 정렬은 공격 실행 승인이 아니다.

여기의 JSON은 팀이 조건과 판정 근거를 정리하는 양식이다. ARTEX가 자동으로 읽는 작업 설정이나 실행 스크립트가 아니다. 모든 사례는 `draft`·`enabled=false`·대상 미지정 상태다.

| ID | 후보 | 준비 조건 |
| --- | --- | --- |
| W01 | 서비스·웹 경로 정찰 | 지정 서비스와 공개 경로의 정답 목록 |
| W04 | 객체 접근 권한 | A·B 계정, 소유권이 다른 비공개 더미 자료 |
| W05 | SQL 주입 | SQL DB와 구분된 실습용 검색 기능 |

사이트 기능과 정상 규칙을 정한 뒤 적용 가능한 사례만 선정한다. SQL 기능이 없으면 W05를 제외하거나 파일 경로 등 다른 사례로 대체한다. payload·실제 계정·대상 주소는 이번 준비 단계에서 넣지 않았다.

실행 전에 대상·허용 작업·시간과 요청 한도·정상 대조·원상복구 방법을 확정한다. 각 실행에는 고유 ID를 부여하고 `templates/run-record.json`을 사용한다. W01의 발견 성과와 취약점 재현 성공률은 따로 집계한다.
