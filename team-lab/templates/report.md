## 대상 기능과 정상 동작

대상 기능, 정상 권한 규칙, 더미 자료와 정상 대조 요청을 기록한다.

## 실행 과정과 근거

시각, 실제 요청·도구 실행, 관측 결과, 증거 경로를 연결한다. 모델의 주장과 직접 확인한 결과를 구분한다.

## 모델과 자원 관측

응답·전체 소요 시간, 메모리·스왑, 토큰·호출 수, 도구 호출 오류, 문맥 요약·잘림, 모델 전환 여부를 기록한다.

## 개선과 재시험

사이트 수정과 관제 정책 변경을 구분하고 같은 조건의 공격·정상 요청 재시험 결과를 연결한다.

## 증거 목록과 검토

원본은 Git 제외 경로에 보관한다. 공유용 본문에는 검토한 요약과 허용된 증거만 넣고 검토자·일자를 기록한다.
