# 고객의 소리 사진 첨부 변경본

현재 Victim 소스를 바탕으로 준비한 변경 파일이다. 원본 파일 해시는 `base-sha256.json`에 보관한다. 다른 채팅의 변경이 있으면 해시를 비교하고 재검토한 뒤 적용한다. 수정은 Victim 로컬 소스에 반영했고 별도 DB·합성 계정의 단위 및 HTTP 검증을 통과했다. 기존 실행 사이트의 DB migration과 서비스 반영은 하지 않았다.

- JPEG/PNG 1개·2MiB·4096px 및 1600만 픽셀 이내. 확장자, finfo, getimagesize 교차검사와 일부 PHP 시작 태그를 사용하는 콘텐츠 거부를 적용한다. 이 검사는 정상 이미지 메타데이터의 문자열에도 반응할 수 있고, 악성 여부를 완벽히 판별하지 않는다. GD 재인코딩·백신 검사는 구현하지 않았다.
- 파일은 public 밖에 난수 이름으로 저장한다. 거부 이유와 HTTP 상태를 앱 audit에 남긴다. 파일 원문·원래 파일명은 로그에 저장하지 않는다.
- 비밀글 사진은 본인·현재 담당 부서만 열람하며 공개글 사진도 공개된다. 스트리밍 시 고정 MIME·nosniff, 크기·해시를 확인한다. 게시글 입력 설명에 공개 범위를 표시한다.
- 파일 검증 실패는 문의 접수 전에 중지한다. DB transaction 중 실패하면 DB rollback과 이동된 파일 제거를 시도한다. 프로세스가 강제 종료되는 구간의 고아 파일은 점검이 필요하다.
- `017_customer_ticket_files.sql`은 신규 테이블을 준비하며 실제 DB에는 아직 적용하지 않았다. 새 schema를 적용하기 전 새 상세 화면을 배포하지 않는다.
- `storage/customer-ticket-files/`를 Git/Docker 컨텍스트와 이전 공개본에서 제외한다. 저장소는 기존 storage 디렉터리 권한을 사용한다.

검사: `php tests/customer_photos_domain.php`는 임시 파일과 합성 권한으로 검증하며 네트워크·DB를 사용하지 않는다. 실제 multipart 처리·DB rollback·브라우저 표시·Snort 경보는 별도 통합 검증이 필요하다.
