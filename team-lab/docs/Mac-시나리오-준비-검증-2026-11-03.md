# Mac 시나리오 준비·검증 기록

- 날짜: 2026-11-03 · Asia/Seoul
- 대상: Mac 로컬 ARTEX, Victim 소스 및 분리 시험 환경
- 범위: MFA·사진 첨부 보완, 사용자 스캔 도구 준비와 오프라인 검증. 탐지 룰·실제 공격·PHP CVE 재현 제외.

## 확인한 결과

- Victim 소스의 MFA 전환 시 남은 대기 세션, TOTP secret 대소문자에 따른 재사용 방지 문제를 보완했다. 새 compose 예시는 기본 비활성이다. MFA 등록 UI·복구 정책·계정별 전역 시도 제한은 아직 없다.
- 정상 PNG의 우연한 2바이트를 스크립트로 오인하던 사진 검사 기준을 구체적인 PHP 태그로 좁혔다. 이것은 악성 여부를 완벽하게 판별하거나 이미지 디코딩·재인코딩을 보장하지 않는다. 웹 공개 경로 밖의 보관과 접근 제어를 함께 사용한다.
- 기존 운영 DB가 아닌 별도 시험 DB·합성 계정·공개 RFC 시험 키를 사용했다. MFA 단위 38개, 사진 단위 22개, 기존 문의 단위 19개를 통과했다. HTTP에서 MFA 로그인·누락/변조/다른 세션·재사용 거부, 기존 PNG 첨부, 비밀 사진의 비소유자 거부, 공개 사진, 실행 확장자 거부를 확인했다. 앱 감사 이벤트도 확인했다. [시험 요약](../evidence/20261103-isolated-web-check/result-summary.json)은 Git 제외 기록이다.
- 기존 스키마에서 migration 017 적용·재실행과 합성 데이터 보존을 별도 DB에서 확인했다. 단, 원본 `database/schema.sql`이 `USE airport_portal;`을 고정하므로 다른 이름의 시험 DB에서는 **시험 복사본에서만** 그 구문을 제거했다. 이 결과를 원본 스크립트의 임의 DB 대상 지원으로 확대하지 않는다.
- 기존 Mac 사이트 컨테이너·DB는 교체하거나 이전하지 않았다. 사용자 선택에 따라 로컬 미리보기 두 개는 별도 테스트 DB와 합성 데이터로 실행 중이다. 사진 미리보기 `127.0.0.1:59346`, MFA 미리보기 `127.0.0.1:59375`. 포트는 컨테이너 재생성 시 변경될 수 있다.

## ARTEX 사용자 도구

- nmap·sqlmap 사용자 도구를 Mac ARTEX에 비활성으로 등록했다. 에이전트 바인딩과 허용 대상은 비어 있다. nmap은 설치 확인됐고 sqlmap은 설치되지 않았다.
- 실제 ARTEX의 사용자 도구 시험에서 빈 허용 목록이 `not_run`으로 종료됨을 확인했다. 스캔은 하지 않았다. 현재 실행 이미지에서는 이 실패가 `is_error=false`로 반환되는 기존 동작도 관측됐다.
- 소스에서 Python 오류·시간 초과 전달과 Unix 자식 프로세스 정리를 보완했다. 로컬 오프라인 프로세스를 이용한 시간 초과·취소·부모 종료 시험과 관련 Go 검사가 통과했고, Windows용 코드는 교차 컴파일했다. Windows 프로세스 트리 종료 실측은 미실행이다.
- 사용자 지정 도구의 실제 결과를 자동 목표 완료 근거로 인정하는 기능은 미구현 상태로 남긴다. 검토 중 근거 조작과 카탈로그 변경에 따른 판정 문제를 발견해 허용 코드를 제외했다. 현재 실행 이미지에도 소스 보완을 배포하지 않았다. 도구 trace와 완료 판정을 구분해야 한다.
- 검사용 Go 모듈은 `/private/tmp` 임시 캐시에만 다운로드했다. sqlmap 설치·실제 스캔·대상 공격·서비스 보안 규칙 변경은 수행하지 않았다.

## 다음 작업

1. 미리보기의 사진 화면과 MFA 흐름을 사용자와 확인한 뒤 기존 사이트 반영 방법을 결정한다. 실제 MFA 활성화에는 계정별 인증 수단 등록과 비공개 설정이 별도로 필요하다.
2. ARTEX의 사용자 도구 증거를 안전하게 검증하는 설계를 완성하고, 빌드·배포 전에 회귀 검사와 복구 절차를 확인한다.
3. 웹셸용 격리 복제본과 PHP CVE 시험은 별도 준비한다. 현재 생성된 미리보기는 정상 사이트 동작 시험이지 취약 웹셸 환경이 아니다.
4. Windows VM에서는 별도 설치 상태·도구·모델·네트워크를 확인한다. 현재 Mac 결과를 그대로 이월하지 않는다.
